# MyDorm
#### Bеб-портал для автоматизации внутренних процессов общежития

### Для студента
1) Просмотр объявлений от администрации
2) Бронирование стиральных машин
3) Оформление заявок на ремонт
4) Покупка и продажа различных вещей
5) Информация о мероприятиях и их участниках

### Для администрации
1) Выкладывание объявлений
2) Просмотр бронирования стиральных машин и заявок на ремонт
3) Информация о мероприятиях и их участниках с возможностью удаления мероприятий

### Для работников
Просмотр данных заявок по временным слотам с возможностью принятия или отклонения заявки.
